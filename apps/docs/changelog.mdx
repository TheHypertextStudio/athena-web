<Update label="2026-08-15" description="Documentation" tags={["Docs"]}>
  ## Documentation

  Docket has documentation for the first time.

  - **Guides** cover what Docket is, how to create a workspace, the daily loop, the full concept
    vocabulary, and how [Athena](/guides/athena/what-athena-is) works.
  - **Developers** cover the [MCP server](/developers/connect-an-agent-mcp), the
    [REST API](/developers/rest-api), [authentication](/developers/authentication), and the
    [error taxonomy](/developers/errors).
  - **[Terminology](/guides/concepts/terminology)** translates between the words these docs use and
    the words your workspace displays, since workspaces relabel the work hierarchy.

  The developer pages open with [Platform status](/developers/platform-status), which states
  plainly that the API is unversioned, that no SDK is published, and that shapes may change. Read
  it before building anything you intend to keep.
</Update>
