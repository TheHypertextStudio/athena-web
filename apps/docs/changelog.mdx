<Update label="2026-08-15" description="Documentation" tags={["Docs"]}>
  ## Documentation

  Docket has documentation for the first time.

  - **Guides** — what Docket is, how to create a workspace, the daily loop, the full concept
    vocabulary, and how [Athena](/guides/athena/what-athena-is) works.
  - **Developers** — the [MCP server](/developers/connect-an-agent-mcp), the
    [REST API](/developers/rest-api), [authentication](/developers/authentication), and the
    [error taxonomy](/developers/errors).
  - **[Terminology](/guides/concepts/terminology)** — a translation table between the words these
    docs use and the words your workspace displays, since workspaces relabel the work hierarchy.

  The developer pages open with [Platform status](/developers/platform-status), which states
  plainly that the API is unversioned, that no SDK is published, and that shapes may change. That
  page is worth reading before building anything you intend to keep.
</Update>
