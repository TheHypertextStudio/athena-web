<Update label="2026-08-15" description="Documentation" tags={["Docs"]}>
  ## Documentation

  Docket has documentation for the first time.

  - **Guides** cover what Docket is, creating a workspace, the daily loop, the concept vocabulary,
    and [Athena](/guides/athena/what-athena-is).
  - **Developers** cover the [MCP server](/developers/connect-an-agent-mcp), the
    [REST API](/developers/rest-api), [authentication](/developers/authentication), and the
    [error taxonomy](/developers/errors).
  - **[Terminology](/guides/concepts/terminology)** maps the words these docs use to the words your
    workspace displays.

  Building on the API? Read [Platform status](/developers/platform-status) first. It is
  unversioned, has no SDK, and field shapes can change without notice.
</Update>
