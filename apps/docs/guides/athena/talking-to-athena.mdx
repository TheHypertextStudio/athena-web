---
title: 'Talking to Athena'
description: 'Give Athena enough context to answer, plan, or act without guessing what you mean.'
---

Write to Athena in ordinary sentences. You do not need command syntax.

## Open the conversation

Use one of these entry points:

| Entry point                    | Use it when                                              |
| ------------------------------ | -------------------------------------------------------- |
| **Athena in the utility rail** | You want to keep the current page visible.               |
| **Athena page**                | You want more room for a longer conversation.            |
| **Today**                      | The question is about the current day or plan.           |
| **Task assignee or delegate**  | Athena should carry out bounded work in a session.       |
| **Athena email address**       | You want to forward source material from outside Docket. |

Press `Cmd+J` on macOS or `Ctrl+J` on Windows and Linux to open the utility rail.

## Name the result

Ask for the result you need, and include the constraint that would change the answer.

| Instead of            | Ask                                                                              |
| --------------------- | -------------------------------------------------------------------------------- |
| “Sort out my week.”   | “Plan these five Tasks around my meetings, with no work after 6pm.”              |
| “Update the Project.” | “Post an at-risk update on Spring Gala and name the venue delay.”                |
| “Fix Triage.”         | “Move the website Tasks from Triage into Website Rebuild. Leave the rest alone.” |

Use exact Project, Program, Team, or workspace names when two objects could match.

## Ask questions before asking for changes

Athena can summarize work, find blockers, compare actual time, or explain recent activity without
changing anything. For example:

- “What is blocking Spring Gala?”
- “Which Projects have no update in the last two weeks?”
- “How much human and agent time did Website Rebuild use this week?”
- “What changed in this workspace yesterday?”

## Ask for a plan

Ask Athena to draft a plan when the order matters. For example:

- “Plan today around the two calls already on my calendar.”
- “Break this Project into Tasks and keep each Task under half a day.”
- “Draft a recovery plan for the off-track Projects. Do not change any dates.”

Review the proposal before Docket applies changes.

## Answer follow-up questions

Athena pauses when it needs information or approval. The question appears in the conversation and
can also appear in [Inbox](/guides/daily/inbox). Answer it in the active conversation so the
session can continue.

## Set durable preferences

Put recurring instructions under **Settings → Athena** instead of repeating them in every prompt.
Keep one-off constraints in the conversation where they apply.
