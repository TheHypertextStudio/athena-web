---
title: 'Initiatives and programs'
description: 'Use Programs for ongoing work and Initiatives for the outcomes that connect it.'
---

Programs and Initiatives answer different questions. A Program holds work that continues. An
Initiative explains why several efforts belong together.

## Use a Program for ongoing work

Customer support, bookkeeping, and a year-round service belong in Programs. You can put Projects,
recurring Tasks, and individual Tasks directly in a Program.

A Program reports its status, health, recent activity, and the work filed under it. It does not
need a fake completion percentage. Complete or archive the Program when the ongoing work really
ends.

## Use an Initiative for an outcome

Create an Initiative such as “Grow revenue” or “Open a second location” to connect the Programs and
Projects that support that outcome. An Initiative does not contain Tasks of its own.

One Project can support several Initiatives. One Initiative can span several Programs and Projects.
The Initiative rolls up health from the work linked to it.

## Plan an Initiative broadly

Set the target to a precise day, month, quarter, half-year, or year. Broad periods use the
workspace's fiscal calendar. This lets you record “Q3” without pretending that the team committed
to the last Friday of the quarter.

## Nest Initiatives

Nest Initiatives when one outcome supports another. An admin sets the maximum depth under
**Settings → Work structure**. Reducing the maximum does not silently discard existing links.

A cross-workspace link records the relationship. It does not grant access to the other workspace.

## Choose the right object

| Use                                  | When the work                                         |
| ------------------------------------ | ----------------------------------------------------- |
| [Task](/guides/concepts/tasks)       | Is one thing a person or agent does.                  |
| [Project](/guides/concepts/projects) | Has an outcome and a finish line.                     |
| Program                              | Continues and contains real work.                     |
| Initiative                           | Connects efforts to an outcome and contains no Tasks. |

If people will add Tasks directly to it, use a Program instead of an Initiative.
