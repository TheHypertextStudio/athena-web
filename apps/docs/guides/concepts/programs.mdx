---
title: 'Programs'
description: 'Group ongoing work that can contain projects, recurring tasks, and individual tasks without a false finish line.'
---

Use a Program for work that continues. Customer support, bookkeeping, and a year-round service do
not need a made-up finish line.

## Put ongoing work in one place

A Program can contain Projects, recurring Tasks, and individual Tasks. It reports status, health,
recent activity, and the work filed under it. It does not pretend that ongoing work has a useful
completion percentage.

Complete or archive the Program when the ongoing work ends.

Use an [Initiative](/guides/concepts/initiatives) when several Projects or Programs support one
outcome.
