Use a Project for work with a finish line. Spring Gala. Launch v2. Rebuild the donor page. You
close it when it ships.

Put work that never finishes in a [Program](/guides/concepts/initiatives-and-programs).

## What a project carries

| Field | What it holds |
| --- | --- |
| **Lead** | The Actor accountable for the project. |
| **Dates** | A start and a target. Either one can be left empty. |
| **Status** | One of the workspace's own project statuses. |
| **Health** | `on_track`, `at_risk`, or `off_track`, set by the [updates](/guides/concepts/updates-and-health) posted on the project. |
| **Contents** | Milestones, Tasks, attachments, and threaded discussion. |

Docket weights the project's tasks and reports **progress** as one number.

Set "Launch v2" to **depend on** "Rebuild the donor page" when one has to ship first. Attach links,
documents, and items from connected tools as **resources**.

## Milestones

Add a Milestone to a Project to mark a date and gather the tasks due by it. "Beta to design
partners", 14 March. "Invitations mailed", 2 April.

Milestones live inside one project. Add them when people plan around the checkpoint. See
[Cycles and milestones](/guides/concepts/cycles-and-milestones).

## Where a project sits

Put "Fall term enrolment" inside the "After-School Program". Leave "Website rebuild" at the top of
the workspace.

```
Workspace
  ├─ Program "After-School Program"
  │    └─ Project "Fall term enrolment"
  └─ Project "Website rebuild"
```

Link a project to an [Initiative](/guides/concepts/initiatives-and-programs) to say why it matters.
"Website rebuild" can serve "Grow revenue" and "Expand to a second city" at once, and neither one
owns it.

## Templates

Save a template when every client engagement starts the same way, then create the next project from
it. Scope a template to yourself, a Team, or the whole workspace in **Settings → Templates**.

<Note>
  Template Tasks, Projects, Initiatives, and Programs. Cycles and Teams have no document to seed. A
  Cycle is a span of time and a Team is a group of people.
</Note>

## Publishing a project

Publish a project as a read-only **brief** and a funder with no account can read where the Spring
Gala stands. An admin sets the address under **Settings → Publishing**, which can be a custom
domain.
