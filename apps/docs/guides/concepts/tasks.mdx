"Draft the grant report." "Call the caterer." One person, one thing.

## The fields on a task

| Field | Notes |
| --- | --- |
| **Assignee** | One Actor: a person or an agent. Never a team. |
| **Delegate** | Optional. Docket records you as the owner and an agent does the work. |
| **Status** | One of the owning team's workflow states. See [Labels and statuses](/guides/concepts/labels-and-statuses). |
| **Priority** | `none`, `low`, `medium`, `high`, or `urgent`. Docket sorts by it and shows it as a badge. |
| **Due date** | Optional. |
| **Time estimate** | How long you think it will take, in minutes. |
| **Point estimate** | A coarser abstract number, for teams that size that way. |
| **Labels** | Free-form workspace vocabulary. |

A task also has **subtasks**, **attachments**, threaded **comments**, and **dependencies**.

## Fill in the time estimate

Give every task a duration so your day fits.
[Home](/guides/daily/home-today) adds them up and compares the total to the hours you have.

[Scheduling](/guides/daily/calendar-and-scheduling) uses the same number to place the task on your
calendar, and the [time ledger](/guides/daily/time) compares your measured hours against it
afterwards.

**A project is optional on a task.** Record the note you took on a bus, the email that implies
something, the favour someone asked for in a hallway. Docket stores all of it without a project.

## Dependencies

Mark a Task **blocked by** or **blocking** any other Task in the same workspace, including one in
a different project. Docket refuses any dependency that would create a loop. Docket shows blockers
in your daily plan, next to the task they block.

## Recurring work

Define a repeating series once. Docket creates the next occurrence on its cadence.

## Assigning to an agent

Assign a task to [Athena](/guides/athena/what-athena-is) and watch the session, steer it, approve
what she proposes.

To show your own name on the work, assign it to yourself and set the agent as **delegate**.
