## Sign in

Docket supports passkeys and configured sign-in providers. Add another passkey later under
**Settings → Security**.

## Choose personal or shared

Choose a personal workspace for work that belongs only to you. Choose a shared workspace when
other people need membership, Teams, shared connections, or workspace-wide settings.

You can create more workspaces later from the switcher at the top of the sidebar. Creating a shared
workspace does not remove your personal workspace.

## Name the shared workspace

Use the organization or venture name that members will recognize. You can change it later under
**Settings → General**.

The setup choice provides starting terminology. An admin can rename the work objects under
**Settings → General** without changing their behavior.

## Invite people

Open **Settings → Members & Access** to invite members and assign roles. Create Teams when different
groups need their own Task workflows, Cycles, or Triage queues.

## Connect one source

Connect the tool that carries the most useful context. Calendar is a good first choice when you
plan around meetings. Linear or Notion is a better first choice when the main problem is existing
work that nobody wants to copy by hand.

Use [Connections and imports](/guides/manage/connections-and-imports) to choose between ongoing sync
and a one-time import.

## Create the first work

Create one Project with a real outcome. Add the next few Tasks. Leave uncertain Tasks in Triage
until you know where they belong.

Open [Today](/guides/daily/home-today), add the first Task to the plan, and timebox it in Agenda if
it needs a specific hour.
