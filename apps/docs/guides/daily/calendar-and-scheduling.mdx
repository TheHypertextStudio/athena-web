---
title: 'Calendar and scheduling'
description: 'See events and planned work together, timebox tasks, and compare schedules.'
---

Calendar puts connected events, Docket calendar items, task timeboxes, and work locations on one
schedule. Use it to decide when work fits. Docket does not schedule a week for you automatically.

## Move through the schedule

Use **Today** and the arrow buttons to move between date ranges. Open **Display** to change the
calendar axis, the amount of detail, or the timeline scale.

The **Dates** axis shows the schedule across several days. The **People** axis compares the people
you select in one workspace.

## Choose calendars

Open **Calendars** to show or hide layers. A layer can come from a connected provider or from
Docket. When the same provider event reaches Docket through more than one account, the layer menu
can hide the duplicate.

Connect Google Calendar under **Settings → Connections**. Choose which Google calendars Docket
uses under **Settings → Calendar**. See
[Connect your calendar and mail](/guides/connect-calendar-and-mail).

## Create and edit calendar items

Select an empty region of the calendar or use **New** to create an event or a work block. Open an
item to change its title, time, timezone, recurrence, relationships, or notes when the source allows
those changes.

Drag an editable item to move it. Drag an edge to change its length. Docket keeps the original
timezone when it displays a provider event in another timezone.

## Put tasks on the calendar

Drag a task onto an empty time slot to create a 30-minute timebox. You can move or resize that block
afterward. Start the task timer from its calendar block when you begin the work.

The task remains a task. A timebox adds schedule context without changing the task's project,
status, or assignee.

## Add work locations

Set your work-location pattern under **Settings → Work locations**. Calendar and Agenda show those
locations as day context. You can edit one occurrence without rewriting the whole pattern.

## Use Agenda for one day

Open **Agenda** in the utility rail when you only need one day's events and planned tasks. Agenda
uses the same calendar items and task timeboxes as Calendar, so a change in either place appears in
the other.
