---
title: 'Library'
description: 'Find the documents, files, and links that Docket work refers to.'
---

Open **Library** inside a workspace to see the material its work uses. Docket collects documents,
uploaded files, and external pages that appear as resources on visible work.

## Find a resource

Press `Cmd+F` on macOS or `Ctrl+F` on Windows and Linux to open Library search. Search covers the
whole result set, including rows that have not scrolled onto the screen.

Use the other controls to filter, group, sort, and choose the properties shown in the list. Opening
a row shows its details without losing your place.

## Open the source

The main action depends on the resource:

- A web page opens at its original address.
- An uploaded file downloads from Docket.
- Docket work opens inside the app.

Library does not copy a connected document into a second document. It keeps the reference and the
context Docket needs to find it again.

## See where it is used

The detail panel lists visible work under **Used by**. That list includes direct attachments and
places where someone mentioned the resource in Docket prose.

Docket applies normal workspace permissions to both sides. A resource can exist while some work
that uses it stays hidden from you. A row that was removed or is no longer visible opens a clear
unavailable state instead of exposing its old details.

<Note>
  Google Drive can contribute files as planning context after you connect it. Other integrations can
  contribute links and source material through the work they sync.
</Note>
