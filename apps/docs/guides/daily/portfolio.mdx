---
title: 'Portfolio'
description: 'Compare Projects from all your workspaces on one read-only timeline.'
---

Portfolio shows dated Projects from every workspace you can access. It keeps each workspace in its
own band and keeps each Program visible as row context.

## Compare work across workspaces

Use Portfolio to find Projects that overlap even when the work belongs to different organizations.
When more than one workspace has dated Projects, select a workspace chip to focus its band.

Open **Display** to change the timeline scale, grouping, and markers. Use the Today control in that
menu to return the timeline to the current date.

## Open a Project

Select a Project bar to open it in the workspace that owns it. Portfolio is read-only. Change dates
from that workspace's Projects view, where Docket can apply the workspace's permissions and
planning rules.

Projects without a Program remain visible in their workspace band. Projects need a planning period
before Docket can place them on the timeline.

For Project health and updates, open the Project or use a saved
[view](/guides/daily/search-and-views).
