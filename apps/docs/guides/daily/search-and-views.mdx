## The command palette

Press `Cmd+K` to search, jump somewhere, run a command, or switch workspaces.

Type "gala" and the palette matches tasks, projects, programs, initiatives, cycles, teams,
updates, comments, and people across every workspace you belong to. Each result names its
workspace.

Type a command to create a task, set a status, assign someone, or open a settings page.

<Tip>
  Select three tasks in a list, press `Cmd+K`, and the action applies to all three.
</Tip>

## Mentions

Type `@` in a comment, description, or update to mention a task, a person, or a GitHub pull
request from a connected tool. Docket stores a real reference. Rename either side and the mention
follows.

## Saved views

Save a filter you keep rebuilding and give it a name. "Everything assigned to me and overdue."
"This cycle, grouped by status." "Every project without an update in two weeks."

Give the view one of three scopes, the same set [templates](/guides/concepts/projects#templates)
use:

| Scope | Who sees it |
| --- | --- |
| `personal` | You |
| `team` | One team |
| `organization` | The whole workspace |

Scope a view to the team and everyone stops rebuilding the same filter every Monday.

## Search from an agent

[Athena](/guides/athena/what-athena-is) and any agent you connect through the
[MCP server](/developers/connect-an-agent-mcp) search everything the palette searches, under your
permissions. Ask "which projects haven't had an update in two weeks" and save the same question as
a view.
