---
title: 'Search and views'
description: 'Find work with the command palette, and save useful ways to filter and arrange it.'
---

Search helps you find an object or an action. Views keep a useful arrangement of work so you do
not rebuild it every time.

## Open the command palette

Press `Cmd+K` on macOS or `Ctrl+K` on Windows and Linux. Search for work, jump to a page, run an
action, or switch workspaces.

Results name their type and workspace. Your permissions still apply, so Search does not reveal
work that you cannot open.

## Find text in a long list

Press `Cmd+F` or `Ctrl+F` on a supported Docket list. Docket searches the complete loaded result
set instead of asking the browser to search only the rows currently drawn on screen.

## Change a work view

Use the controls above Tasks, Projects, Programs, or Initiatives to change the view:

- **Filter** limits which items appear.
- **Group** collects items under a field such as status or assignee.
- **Sort** controls their order.
- **Display** changes visible properties and presentation details.

Tasks, Projects, Programs, and Initiatives support the layouts that fit their data. These include
List, Board, and Cards. Projects and Initiatives can also use Timeline.

## Save a view

Open **Views** in the workspace sidebar to create and manage saved views. A view records its work
type, layout, filters, grouping, sorting, and display settings.

Save a view after the arrangement answers a question you expect to ask again. For example, save
Projects grouped by health and filtered to one Initiative. Reset the working view when you want to
return to its saved state.

Personal views belong to you. Shared views use workspace access rules.

## Mention an object

Type `@` in supported descriptions, comments, or updates to link another object. Mentions remain
references when either object is renamed.
