## The command palette

`Cmd+K` opens one palette that fuses four things: search, navigation, actions, and switching
workspaces.

Start typing and it looks across everything you can see — tasks, projects, programs, initiatives,
cycles, teams, updates, comments, people. Results carry a chip naming their workspace, because the
palette reaches across your whole Hub.

The same box runs commands. Create a task, change a status, assign someone, jump to a settings
page, switch to another workspace.

<Tip>
  Selecting rows in a list changes what the palette offers — it acts on the selection. Select three
  tasks, open the palette, and the actions apply to all three.
</Tip>

## Mentions

Typing `@` in any comment, description, or update opens the same resolver. It reaches Docket
entities and items in your connected tools, so referencing a GitHub pull request or a Linear issue
beside a Docket task takes one gesture.

A mention is a real reference rather than pasted text, so the thing it points at stays linked when
either side changes.

## Saved views

A view is a filtered, sorted, grouped list you have named and kept. "Everything assigned to me and
overdue." "This cycle, grouped by status." "Every project without an update in two weeks."

Views are scoped, the same way [templates](/guides/concepts/projects#templates) are:

| Scope | Who sees it |
| --- | --- |
| `personal` | You |
| `team` | One team |
| `organization` | The whole workspace |

Team and workspace views are how a group agrees on what "the list" means, so nobody rebuilds the
same filter every Monday.

## Lists behave the same everywhere

Tasks, projects, and initiatives all render through the same list, with aligned rows and the same
filtering, sorting, grouping, and selection. Learning it once is enough.

Drag and drop works across the app: onto a project in the sidebar to re-file work, onto a day to
schedule it, onto today's plan to commit to it.

## Search from an agent

Everything the palette searches is also reachable by [Athena](/guides/athena/what-athena-is) and
by any connected agent through the [MCP server](/developers/connect-an-agent-mcp), under your own
permissions. "Find every project without an update in two weeks" works as a sentence as well as a
saved view.
