---
title: 'Search'
description: 'Find work and actions with the command palette, or search every loaded row in a supported list.'
---

Search finds objects and actions without requiring you to remember where they live.

## Open the command palette

Press `Cmd+K` on macOS or `Ctrl+K` on Windows and Linux. Search for work, jump to a page, run an
action, or switch workspaces.

Results name their type and workspace. Your permissions still apply, so Search does not reveal work
that you cannot open.

## Search a long list

Press `Cmd+F` or `Ctrl+F` on a supported Docket list. Docket searches the complete loaded result
set instead of asking the browser to search only the rows currently drawn on screen.

Use [Views](/guides/daily/views) to keep a filter and layout that you return to often.
