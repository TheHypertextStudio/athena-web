---

The personal Stream shows events across every workspace you can access. A workspace Stream limits
the same timeline to that workspace.

## Read related changes together

Stream groups related events into episodes instead of showing each field change as an isolated
notification. Select an event to open its details.

Use **Filters**, **Group**, and **Sort** to narrow the timeline. A banner lets you reveal new events
without moving your reading position.

Connected tools can add events to Stream. Each event keeps its source and links back to the object
that produced it.

Use [Inbox](/guides/daily/inbox) when a notification needs a response from you.
