Open **Tasks** under Home to see work assigned to you across every workspace. Open **Tasks** under
Workspace to see that workspace's full task list. **My Work** narrows the same workspace to work
that involves you.

## Change how the list reads

Use the controls above a task list to filter it, group it, choose a layout, and decide which
properties appear. Tasks support List, Board, and Cards.

Press `Cmd+F` on macOS or `Ctrl+F` on Windows and Linux to search the complete list. Docket searches
rows that have not scrolled onto the screen yet.

Save a setup when you will ask the same question again. A saved View keeps its filters, grouping,
sorting, layout, and displayed properties. See [Search and views](/guides/daily/search-and-views).

## Sort the triage queue

Triage lists tasks that have no Project or Program. Captured work and tasks created from connected
tools can wait here until someone decides where they belong.

Each row shows where the task came from. Open **Sort this item** to:

- Move the task into a Project.
- Send the task to a Program.
- Dismiss it when it is not work you intend to keep.

Moving a task clears it from Triage. Dismiss archives it. Open the task first when you need to edit
its title, assignee, status, or other properties before filing it.

## Start without filing

A Task does not need a Project. You can assign it, start its timer, or open its details while it is
still in Triage. File it once the right destination is clear.

<Tip>
  Keep Triage for decisions. Use a saved View for work that is already filed but still needs a
  recurring review.
</Tip>
