---
title: 'Work with tasks'
description: 'Find assigned work, change how task lists read, and work without filing every task into a project.'
---

Open **Tasks** under Home to see work assigned to you across every workspace. Open **Tasks** under
Workspace to see that workspace's full task list. **My Work** narrows the workspace to tasks that
involve you.

## Change the list

Use the controls above the list to filter, group, sort, choose a layout, and decide which properties
appear. Tasks support List, Board, and Cards.

Press `Cmd+F` on macOS or `Ctrl+F` on Windows and Linux to search the complete list. Docket also
searches rows that have not scrolled onto the screen yet.

Save the setup when you expect to ask the same question again. A saved
[View](/guides/daily/views) keeps the filters, grouping, sorting, layout, and displayed properties.

## Work before you file

A Task does not need a Project. You can assign it, start its timer, or open its details while it is
still in Triage. File it once the right destination is clear.

Use [Triage](/guides/daily/triage) to sort unfiled work into a Project or Program.
