---
title: 'Triage'
description: 'Sort captured and imported tasks into the right project or program, or dismiss work you will not keep.'
---

Triage holds Tasks that have no Project or Program. Captured work and Tasks created from connected
tools can wait here until someone decides where they belong.

## Sort one item

Each row shows where the Task came from. Open **Sort this item** to move it into a Project, send it
to a Program, or dismiss it.

Moving a Task clears it from Triage. Dismiss archives it. Open the Task first when you need to edit
its title, assignee, status, or other properties before filing it.

## Leave work unfiled when that is correct

You can assign an unfiled Task, start its timer, and work from its detail page. Triage is a queue
for filing decisions. It does not block the work itself.

<Tip>
  Keep Triage for decisions. Use a saved [View](/guides/daily/views) for filed work that needs a
  recurring review.
</Tip>
