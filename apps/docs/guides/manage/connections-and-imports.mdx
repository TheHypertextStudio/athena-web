---
title: 'Connections and imports'
description: 'Choose between ongoing sync and a one-time move into Docket.'
---

Use **Connections** when another tool will keep running beside Docket. Use **Import** when Docket
will take over the work and the old tool can stop being the working copy.

## Link your account first

Open **Settings → Connected accounts** to link a Google, GitHub, Linear, or Notion identity. This is
your sign-in and consent relationship with the provider.

Then open **Connections** for the personal or shared workspace that should use it. A shared
workspace connection is available to people who have access to that workspace. Admins manage its
configuration.

## What each connection does

| Connection          | What Docket uses it for                                                   |
| ------------------- | ------------------------------------------------------------------------- |
| **Google Calendar** | Plan around events and write scheduled work back when editing is enabled. |
| **Google Tasks**    | Mirror selected task lists into a Docket Team.                            |
| **Gmail**           | Turn actionable messages into task suggestions.                           |
| **Google Drive**    | Find files and use them as planning context.                              |
| **GitHub**          | Link pull requests and issues to Docket work.                             |
| **Linear**          | Sync issues, Projects, and Cycles by Team.                                |
| **Notion**          | Sync designed databases with Docket work.                                 |

The connection card says whether it is connected, disconnected, or needs attention. Open the
provider's configuration to choose lists, Teams, databases, repositories, and sync direction where
that provider supports them.

## Understand write-back

Google Tasks and Linear can run as an import-only mirror or sync edits in both directions. Notion
can sync both directions with Docket in charge when the same field changed on both sides. Docket
keeps the displaced Notion value in sync history.

Google Calendar separately reports whether editing is enabled or the calendar is read-only.

## Move work once

Open **Settings → Import** when you are leaving another tool. Review the destination and mapping
before you start. An import is not a live connection and does not promise continuing write-back.

<Warning>
  Disconnecting a provider stops future sync. It does not mean that Docket should delete work the
  connection already created.
</Warning>
