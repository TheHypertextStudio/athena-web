---
title: 'Imports'
description: 'Move work into Docket once, review the destination and mapping, and avoid promising an ongoing sync.'
---

Use **Settings → Import** when Docket will take over work from another tool and the old tool can stop
being the working copy.

## Review before you start

Choose the destination workspace and Team. Review how source fields map to Docket work before you
start the import.

An import is a one-time move. It does not keep the source and Docket in sync after it finishes.
Use [Connections](/guides/manage/connections) when both systems must keep running.
