---
title: 'Publishing'
description: 'Publish a read-only project brief, manage its address, and review the signed-out result before sharing it.'
---

Publish a Project when someone outside Docket needs a read-only status page. The brief shows the
Project's current public information without giving the visitor a Docket account.

## Manage the address

An admin opens **Settings → Publishing** to manage the default workspace address and custom
domains. The **Primary** badge marks the address visitors should use. Changing an address does not
change the Project.

<Warning>
  Publishing is an access decision. Review the brief in a signed-out browser before sharing its
  address.
</Warning>
