---
title: 'Configure how work moves'
description: 'Set terminology, statuses, labels, hierarchy, and the fiscal calendar for a workspace.'
---

Open a workspace's Settings when its work should use different language or rules. These changes
apply to that workspace only.

## Change the words Docket uses

Open **Settings → General** to choose a terminology preset or edit the six work nouns. Docket uses
those names in navigation and work screens. The documentation continues to use the default words so
one link stays readable across every workspace.

See [Terminology](/guides/concepts/terminology) for the default meanings.

## Configure statuses

Open **Settings → Statuses** to edit the states used by Tasks, Projects, Programs, and Initiatives.
Task workflows belong to Teams. Strategic work uses workspace-level status sets.

Each status also belongs to a stable category such as backlog, started, completed, or canceled.
Docket uses the category for behavior and rollups while the workspace controls the visible name.

## Configure Labels

Open **Settings → Labels** to create the workspace's reusable tags. Labels never cross a workspace
boundary. Add them to work directly or expose them as a property in a View.

## Set Initiative depth and planning periods

Open **Settings → Work structure** to set the maximum Initiative nesting depth and the fiscal start
month used by broad planning periods.

Projects and Initiatives can use a precise day, month, quarter, half-year, or year. Docket saves the
period and its fiscal basis together. Changing the workspace calendar later does not silently move
an existing plan.

Dragging a broad period freely on a day-level timeline converts it to precise dates. That move no
longer lands on the original month or quarter boundary.
