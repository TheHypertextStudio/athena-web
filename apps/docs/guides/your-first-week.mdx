---
title: 'Your first week'
description: 'Set up one real workflow, plan each day, and review what happened at the end of the week.'
---

Do not configure every part of Docket before you use it. Start with one Project and enough Tasks to
plan a real day. Add structure after the work exposes what you need.

## Day 1: connect the schedule

Connect Google Calendar under **Settings → Connections**. Choose the calendars you want Docket to
show under **Settings → Calendar**. Add your normal work-location pattern if it changes how you
plan the week.

Create one Project with a finish line. Set a precise target or choose a month, quarter, half-year,
or year when the date is not firm.

## Day 2: plan Today

Open [Today](/guides/daily/home-today). Add the Tasks that matter now. If the day is empty, use
**Plan today with Athena** and review the proposed plan in the utility rail.

Keep the current Task in **Now** and the next few Tasks in **After this**. Timebox work in Agenda or
[Calendar](/guides/daily/calendar-and-scheduling) when it needs a specific place.

## Day 3: clear Triage

Open [Triage](/guides/daily/tasks-and-triage). Move each captured Task into the right Project or
Program, or dismiss it. A Task can stay outside a Project when that is the correct shape.

Create a saved [View](/guides/daily/search-and-views) only after you have rebuilt the same filter
more than once.

## Day 4: delegate one Task

Assign a bounded Task to Athena or keep yourself as the assignee and set Athena as the delegate.
Watch the session. Answer any question it raises, and approve or reject proposed changes.

See [Talking to Athena](/guides/athena/talking-to-athena) for useful prompts and
[Proposals and approvals](/guides/athena/proposals-and-approvals) for the review controls.

## Day 5: review the week

Post a Project update and set its health. Then open [Time](/guides/daily/time), select **Week**, and
compare human and agent effort. Break the total down by Project or Task and open the sessions behind
any surprising number.

Use [Stream](/guides/daily/inbox) when you need the history behind a change. Use
[Portfolio](/guides/daily/portfolio) to check whether dated Projects overlap across workspaces.

## Add workspace rules when they become necessary

An admin can change statuses, labels, terminology, Initiative depth, and the fiscal calendar under
Workspace Settings. Keep the defaults until a real workflow needs a different rule.
