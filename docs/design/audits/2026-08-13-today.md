# Design review: Athena-guided Today — 2026-08-13

**Verdict: SHIP.** Today now behaves as a finite daily operating surface: Athena is the standing
entry point, an untouched day makes planning unmistakable, an accepted day names only Now and
After this, and a cleared day offers grounded work that can still fit. Detailed workflows still
open their canonical Task, Project, Initiative, Calendar, or Athena surfaces.

The authenticated browser journey exercised an unplanned day, a real accepted plan, semantic Task
completion, focus advancement, status cards, and the cleared-day suggestion state. Its 320px probe
reported no document overflow or undersized Today controls, and the Today-scoped console error
count was zero. Focused component tests cover the Athena-default composer, keyboard reorder
announcement, timebox editor, local dismissal, all three plan states, application-owned failures,
and optimistic cache reconciliation.

## Findings resolved during review

1. The original page left the center of the app blank after one capture line. The three plan states
   now each carry a finite, useful operating surface.
2. Athena was visually detached in a floating launcher. The persistent top field now opens the same
   personal session in place, and an untouched day gives planning primary emphasis.
3. Completion originally risked updating only the plan row. Today now uses one semantic server
   action that advances the real Task workflow and the personal plan together.
4. After this initially had no way to become Now and neither focus item could be scheduled. A
   one-write promote action, shared wall-clock timebox editor, optimistic cache projection, and
   keyboard announcement close those interaction gaps.
5. Status cards initially omitted durable-update age and target timing, and related stories could
   repeat. Cards now show honest recency/dates while the server de-duplicates connected stories and
   prefers an equally relevant workspace before repeating one.
6. Start now initially used the daily-plan default sort and could land behind completed rows. It
   now inserts before the current minimum; Add to today appends after the current maximum.

## Limitations

- The standard four-capture matrix uses the Unplanned state because it is the only state stable
  enough for identical cross-theme geometry. Separate populated captures prove Active and Cleared
  composition; their semantic colors are token-driven and covered by the same theme system.
- The final browser connector became unavailable after the populated journey completed, so the
  last source-only additions (update age, target dates, and the compact More menu) are verified by
  component tests, type checking, linting, and the earlier 320px geometry harness rather than a
  second redundant browser run.
