## Gates

**Accessibility.** The reorder has a first-class keyboard path: the grip is a toggle button
carrying `aria-pressed`, Space/Enter grabs and drops, arrows move, Escape cancels and restores, and
every move is announced into an `aria-live="polite"` region naming the status and its new position.
Focus never leaves the grip. `Alt+Arrow` moves without the grab step for anyone who does not
discover the toggle. The category radios are `sr-only` inside their labels — the standard pattern,
and the reason the evidence spec clicks the label rather than the input.

**Responsive.** Desktop is correct. At 390px the content column is squeezed and clips — **and so is
every other settings page**, because the shell keeps its section nav beside the content at that
width. `control-labels-mobile-light.png` is the untouched Labels page at the same width, showing the
identical squeeze with its own copy clipped. This page adds `min-w-0` at every level so it never
contributes to the overflow, and the remaining narrowness belongs to the settings shell. Recorded
here rather than fixed, because fixing it means changing the shell for all fifteen settings routes.

**Theme parity.** Captured light and dark at both widths. Glyph colours come from the `--state-*`
tokens, which are declared in both theme blocks.

**No placeholder.** Every control does something. There are no read-only "Not set" rows: a status
can be renamed, re-described, re-categorized, made the default, reordered, and deleted from this
page.

**Screenshots.** 15, listed above.

## What this review changed

1. The category header duplicated its own rows; it is now a single muted label, and the category's
   meaning moved into the empty slot where it explains what would go there.
2. The editor title used the plural vocabulary word.
3. `min-w-0` throughout, so the page never widens its own container.
4. The Labels page still described statuses as "Docket's opinions". That was true until this work
   shipped and is now false, so its header copy and module note were corrected to draw the real
   line: labels name a dimension Docket does not model; statuses reshape one it does.

## Known and deliberate

- **A seeded workspace reads its category label and its first status name as the same word**
  ("Backlog" over "Backlog"). That is the seed data, not the layout: a workspace that renames the
  status to "Icebox" reads correctly, and the label is muted precisely so the repetition is quiet.
- **No per-status colour.** The category owns it. This is the one place the design departs from
  Linear, and it is what makes a glyph mean the same thing in every workspace.
- **The team selector is absent for a workspace with one team**, because forking away from a set
  nobody else holds is a decision with no content.
