# Calendar polish audit — 2026-08-22

This record is for the Athena maintainers who will change Calendar or Agenda next. Keep the shared
scheduling surface intact, keep sync state out of its geometry, and use the screenshots below when
reviewing a visual change.

The calendar now reads as a seven-day planning surface at 1440 by 900. Events are solid blocks,
timeboxes are translucent dashed regions, and work location is a small all-day chip or thin timed
rail. A decorative connector derives overlap without giving either domain ownership of the other.
The centered event dialog replaces the right drawer and keeps its own internal scrollport.

## Findings closed

The schedule no longer adds work-location sync text above the grid. Location refreshes keep a fixed
all-day context height, so a refetch changes the rail or chip content without moving the time grid.
Provider health remains outside scheduling geometry.

The desktop Calendar does not mount the right task or focus rail. That rail left four 160px day lanes
at 1440px. Calendar now reserves its width for the grid and uses a 144px readable lane floor, which
renders Friday 21 through Thursday 27 together. The Toolbar remains the one place for navigation,
display controls, calendars, and creation.

The Agenda rail uses the same `SchedulingCanvas` composition. The reviewed frames show the same
Home chip, Studio rail, blue event blocks, and dashed timebox treatment. The connector remains
presentational; moving a location or timebox recalculates it from the new ranges rather than writing
across domains.

The item editor is a centered modal with an internal scroll region. It presents Event details,
Related events, and Tasks. It does not expose provider event, provider metadata, calendar
relationships, or sync labels. The quick-create dialog retains the separate draggable desktop
editor and visible Event/Timebox choice.

pins the no-right-rail rule for Calendar. The existing scheduling, location-composition, import

inside it. It is the clock marker, not an event error or sync indicator.
