   the current workspace. Final desktop and 320px captures confirm it remains visible.
2. **Corrected: included-work rows looked passive.** Child rows now have a trailing chevron;
   entering one replaces the outline, and Back restores row focus.
3. **Corrected: competing phone navigation.** The phone header presents only the current step
   until its chooser opens. Kind filtering and maintenance remain disclosures on the overview.
4. **Corrected: retained help failed in the actual runtime.** Shared Sheet retention now provides
   a DOM presence anchor. StrictMode regression coverage and the real canvas browser journey pass.
