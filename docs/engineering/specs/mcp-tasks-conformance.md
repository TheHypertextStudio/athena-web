# MCP Tasks conformance matrix

**Extension:** `io.modelcontextprotocol/tasks`
**Version, as published by the source:** `draft`
**Spec copy:** `docs/engineering/specs/vendor/mcp-tasks-draft.md`
**Retrieved:** 2026-08-02

Unlike `docs/engineering/specs/mcp-apps-conformance.md`, this matrix is **hand-authored**, not
generated and enforced by a script that cross-checks the vendor spec's own method/notification
list. Building that generator was out of scope for this pass. Every row below was written by
reading the committed spec copy directly and locating the file/function/test that implements it;
treat it as an honest snapshot, not a self-checking artifact.
