# Get back on track

Stop the repeated action now, without a last check. Return to the predefined Docket assignment,
compare current activity with its unmet criteria, and execute the next action that advances it.
The conversation supplies the user's latest steering; recovery grants no additional authority.

Read [Recovery](references/recovery.md) to resolve the assigned record, identify the gap, choose an
action, and finish or report the real blocker. Read [Monitoring](references/monitoring.md) when a
poller is running or waiting is the remaining dependency; preserve useful jobs and the aggregate
wait limit across turns. Read [Agent assignments](../../references/agent-work.md) when recovering
project, initiative, or program responsibility. Read [Subagents](../../references/subagents.md)
when coordination has become the distraction. Read [Working in Docket](../../references/work-management.md)
before work tools.

Reuse the known task/project/initiative/program reference. Resolve ambiguity before choosing a
record; use prior context provisionally when access fails. Do not create replacement work or expand
from a task into its parent mandate. Honor explicit user exceptions to Docket tracking.

Give one short recovery note: the work reference, intended result, remaining criterion, the detour,
and next action. Execute that action in the same turn and continue dependent authorized work.
A record read or a plan alone is not recovery when useful work remains.

Verify at the assigned level and return authorized results to the original records. Preserve
requirements and record outcomes outside descriptions. Report completion when the requested result
and its required gates are established; otherwise identify the observed prerequisite. Do not replace
CI polling with repeated searches, delegation, skill reads, or new monitoring.
